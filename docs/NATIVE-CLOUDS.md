# 六家原生网盘接入（2.12.0）

阿里云盘、123 云盘、115、天翼云盘、中国移动云盘、迅雷云盘直接使用对应平台接口，不依赖 OpenList 或第三方授权中转。账号页按平台显示已实现的登录按钮，也保留「高级凭据…」用于已有授权的导入和修订。

| 平台 | 扫码登录 | 密码登录 | 前置条件与验证 |
| --- | --- | --- | --- |
| 阿里云盘 | 支持开放平台扫码 | 未接入 | 填写获授权应用的 Client ID / Secret，使用阿里云盘 App 确认 |
| 115 | 支持开放平台扫码 | 未接入 | 填写开放平台 App ID，使用 115 App 确认；本地 PKCE 兑换令牌 |
| 天翼云盘 | 支持 | 支持 | 密码登录按平台要求完成图片、短信设备验证 |
| 123 云盘 | 未接入 | 支持网站账号密码 | 网站令牌与开放平台令牌分别路由，仍受验证与下载权益限制 |
| 中国移动云盘 | 未接入 | 支持 139 邮箱 / 手机号服务密码 | 支持已接入风险场景的短信验证；其他验证先在官方网页完成 |
| 迅雷云盘 | 未接入 | 支持 | 设备 / 交互验证需打开官方验证页面完成后重试，不能继续时可用高级凭据导入 |

不是六家都同时支持两种登录方式。阿里 / 115 仍需对应应用权限，ZERA 没有可供所有用户共享的开放平台应用授权。

在「账号」页选择平台，点击「扫码登录…」或「账号密码登录…」。可自定义账号名称。扫码后在手机确认；密码登录可能要求图片或短信验证，短信只在点击「发送短信验证码」后发送。认证完成后继续验证网盘身份，通过才加密保存和切换，失败保留原账号。之后在下载页「我的网盘」浏览并选择文件或目录，加入下载队列；通过「切换 / 管理账号」切换账号。

二维码过期可重新获取，关闭或重新开始登录会取消未完成的请求与轮询。账号身份验证和保存阶段需等待结果，避免部分提交。原始密码、密码哈希、图片答案和短信验证码不写入配置，重启复用已获授权的令牌 / 会话。不会自动识别验证码、反复提交密码或绕过手机确认。

高级导入时点击「高级凭据…」，选择正确的授权类型，测试通过后保存。123 必须选择与令牌一致的「开放平台令牌」或「网站登录令牌」。

| 平台 | 所需授权信息 | 续期方式 |
| --- | --- | --- |
| 阿里云盘 | 阿里云盘开放平台 Access Token；或同一应用 Client ID、Client Secret、Refresh Token | 配齐应用信息和 Refresh Token 后，授权失效时刷新一次 |
| 123 云盘 | 开放平台 Client ID / Secret / Access Token，或选择网站登录令牌 | 开放平台可重新获取令牌；网站授权过期需重新密码登录 |
| 115 | 开放平台 Access Token / Refresh Token | 有 Refresh Token 时自动刷新；新 Refresh Token 加密保存 |
| 天翼云盘 | PC Session Key + Session Secret；或 PC Access Token | 有 Access Token 时可换取 PC 会话；Access Token 失效需重新授权 |
| 中国移动云盘 | 官方网页版 Authorization 请求头的 Basic Base64 值 | 本版不自动续期，失效后重新导入 |
| 迅雷云盘 | 当前会话 Access Token、Device ID，及需要时的 Captcha Token、User-Agent | 同一应用 Client ID / Secret 与 Refresh Token 齐全时可刷新；验证码需要人工在官方页面完成 |

阿里、123、115 的开放平台令牌需从对应开放平台授权流程获取，普通网站 Cookie 不能直接替代。阿里的普通网页 Refresh Token 也不能当作开放平台 Refresh Token。阿里、115 的扫码由用户自己的授权应用发起，不使用 OpenList 的应用或中转。

天翼、移动和迅雷登录使用对应客户端协议，受服务端变动、设备验证及风控影响。移动使用 139 邮箱服务密码，不保证普通通信账号密码或所有组织账号均适用。本版不自动提取浏览器凭据。高级导入的迅雷会话字段需要来自同一会话，115 和迅雷 User-Agent 应与授权会话匹配。

123 网站模式使用独立账号键和对应 API；任务保存原文件元数据，重启可按原模式刷新直链。不会把网站令牌发往开放平台，也不会在切换登录模式时静默改变任务身份。网站下载可能先返回 302 或 JSON 网关，程序继续解析到文件地址，并为每个文件保留对应 Referer。

## 支持范围

- 提供目录分页、原文件取链、目录递归下载、任务账号绑定和按原文件 ID 刷新直链，下载复用现有分片引擎。
- 天翼和中国移动当前接入个人云，不包括家庭云、群组空间；阿里使用服务端默认云盘。
- 新增六家暂不提供分享链接解析、转存、上传、文件修改、容量或会员查询。
- 开放平台申请、接口授权、下载权益、付费要求和限速由各平台决定；ZERA 不保证任何账号都能调用下载接口，也不保证满速。
- 分片及断点恢复依赖返回的下载地址支持 HTTP Range；远端文件需要保持不变。默认建议 2 线程、4 MiB 请求，实际调度仍受下载设置影响。
- 分页游标重复、目录超出调用方分页上限或响应缺少列表时明确报错，不把不完整列表显示成完整目录。

## 保存与错误处理

账号及设置使用当前 Windows 用户 DPAPI，加密失败拒绝明文保存新增平台凭据。下载请求不携带网盘 API Authorization、Session Key 或 Captcha Token，使用直链、对应 User-Agent 及必要 Referer。API 凭据只发往对应平台 HTTPS 域名；登录页必要跳转逐次检查白名单。移动个人云路由限制官方 yun.139.com 域名范围。图片、JSON、下载网关响应均有大小和读取时间限制。

授权失败最多自动刷新一次，不循环重试验证码和限流。日志保留 HTTP 状态、可识别错误代码及处理提示，不输出原始 API 响应、令牌或会话秘密。自动刷新后的令牌按原平台和账号档案保存，不覆盖正在使用的另一个账号。

## 验证边界

模拟认证覆盖三家扫码、四家密码、PKCE、RSA / 哈希传输、图片和短信验证、取消、失败脱敏，以及 123 网站目录、网关和重启取链。实际 WPF 窗口检查二维码可解码、深浅主题、能力入口、关闭取消、密码遮罩和异步提交；DPAPI、现有下载、账号、WebDAV、BT / Tracker 流程另行回归。

当前没有六家可用的测试账号，尚未完成真实账号授权和实际平台下载联调。模拟通过不等于真实平台全部可用，尤其是应用授权、设备验证、反自动化和下载权益，需要真实账号进一步确认。
