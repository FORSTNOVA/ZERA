# 统一网盘适配层

ZERA 2.8.0 提供夸克、百度和 WebDAV 三个平台注册项。适配器编译随程序分发，不加载未知 DLL，也不是填写任意网盘官网就能自动登录。

## 分层与已有能力

- `IPanelClient` 是登录校验、容量、目录、文件取链、续传刷新和下载请求上下文的统一契约。
- `PanelRegistry` 创建客户端并声明浏览、分享、扫码、Cookie 登录、转存和会员查询能力。
- `PanelAdapter` 将提供商的账号标识、登录资料、保活、分享目录、批量取链、转存与会员查询差异封装在核心库。
- `QuarkAdapter` / `BaiduAdapter` 复用已经验证的 HTTP 客户端；界面不直接实例化这些提供商客户端，也不再持有夸克专用客户端引用。两家的扫码进度界面仍使用各自的二维码服务。
- `WebDavClient` 实现通用契约，复用现有文件列表、下载队列和分片引擎。`QuarkFileEntry` 保留历史类型名，但作为通用条目承载所有平台数据。
- `MainWindow` 负责呈现、任务调度与用户交互，不构造提供商 HTTP 请求。平台分享流程和专属操作仍由能力开关与适配器路由。

## 账号与任务隔离

各平台各自记住上次账号。账号目录及设置沿用原格式，WebDAV 在旧枚举末尾追加为值 2，夸克 0 和百度 1 保持不变。
旧档案匹配到同一登录凭据时保留旧账号键；夸克拿不到服务端账号 ID 时使用凭据指纹，避免昵称相同导致覆盖。
新任务保存平台与原账号键；后台与重启续传从原账号构造请求上下文，缺少原档案时提示重新登录，不静默改用另一服务器。
旧任务没有账号键时保留旧版的平台槽位行为。更换存在未结束任务的平台账号仍受保护。

## WebDAV 使用

1. 在“账号”页选择 WebDAV，点击“接入 / 编辑 WebDAV”。
2. 填写名称、完整 WebDAV 根地址（包括服务路径）、用户名、密码或应用专用密码。
3. 使用 HTTPS 和有效证书；确有 HTTP 服务时需勾选允许未加密连接。匿名服务可将用户名和密码都留空。
4. 点击“测试连接并保存”。通过后进入“我的网盘”，可浏览、选择文件或目录并下载。
5. 在统一账号列表中切换已保存的不同服务器/账号。修改当前 WebDAV 连接可再次打开配置窗口。

PROPFIND 207 多状态响应只采纳成功属性，处理命名空间、中文/空格/井号编码，过滤自身、越界及非直接子条目。容量信息是可选的；服务器不返回时不臆造容量。
支持标准 UTF-8 Basic 认证及匿名服务。OAuth、Digest、NTLM、交互式 SSO、仅浏览器登录的页面和私有验证码流程不在本版支持范围。
只提供读取、浏览、下载和续传，不提供 WebDAV 上传、删除、移动、建目录或网盘分享解析。

## 下载与凭据

WebDAV 下载的 Authorization 与服务器根范围只存在于内存上下文，续传记录只存平台、账号键和文件标识；不会把密码写入下载元数据。
下载不附带夸克或百度的 Cookie、Referer、Origin。请求只能到配置的源与根路径；不跟随重定向，请直接配置最终服务地址。跨源对象存储重定向的 WebDAV 网关暂不支持。
PROPFIND XML 禁止 DTD/外部实体，限制响应大小并设请求和读取超时。错误只显示状态，不将任意服务返回的正文写入下载日志。
WebDAV 配置与账号密码用 Windows 当前用户 DPAPI 加密；加密失败时拒绝保存该凭据，不沿用旧 Cookie 的明文回退。
分片和断点续传取决于服务器正确支持 HTTP Range；不承诺每种服务端扩展或代理配置都兼容。服务器上的文件在下载期间应保持不变。

## 扩展新平台

实现 `IPanelClient`，将平台特有的可选操作放入适配器，在 `PanelRegistry` 注册工厂和能力；为新增登录形式补充界面入口。
验证普通下载、取消后续传、错误传递、跨平台账号隔离及旧数据兼容。平台专属功能不能在未声明支持时默默调用另一家接口。
