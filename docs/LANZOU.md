# 蓝奏云分享下载（2.13.0）

在下载页粘贴完整分享链接，填写提取码后点击「解析」，选择文件再下载。粘贴包含链接和提取码的整段文案也可以。识别到蓝奏链接时，点击解析会自动切换平台；也可手动选择「蓝奏云」。无需账号登录。

## 已实现

- 普通蓝奏云 `lanzou*.com` 和 `lanzn.com` 分享地址，使用严格的主机名匹配，不把包含类似文字的其他网站当作蓝奏。
- 无密码和有提取码的单文件；文件夹按页列出文件及子目录。每次最多 40 页，超过上限明确报错，不把部分目录当作完整结果。
- 旧版 `ajaxm.php` 和新版官方 `ajaxfile.php`；读取页面静态参数，原生调用蓝奏接口，不依赖第三方解析站，不执行网页 JavaScript。
- 下载网关的重定向、表单取链及标准 `acw_sc__v2` 浏览器 Cookie 校验。人工验证码不自动处理。
- 文件夹中的文件保留原分享提取码，子文件夹使用自己的分享上下文。每个任务保存自己的文件分享信息，切换分享不会改变旧任务的刷新来源。
- 临时直链失效时重新解析原分享。重启后从未完成任务列表手动继续，不会自动开始下载。实际 Range 支持和分享仍有效是续传前提。
- 默认建议两个下载连接、单次 Range 最多 4 MiB；下载引擎会探测实际长度和 Range 支持。页面大小常有四舍五入，仅供列表展示。

## 边界

不支持蓝奏优享 / ilanzou、登录个人蓝奏账号、转存、上传或修改远端文件。分享取消、文件删除、提取码错误、安全验证、HTTP 错误和解析参数变化都会显示原因。网关域名采用当前已知范围，出现新域名会明确报错，需要更新适配。

分享链接及提取码作为续传所需的信息保存在本地任务记录中；文件标识的 Base64 编码不是加密。蓝奏适配不会读取或发送其他网盘账号的 Cookie、密码或令牌。只有下载网关所需的公共 Cookie 和该站临时校验 Cookie 参与解析。

## 验证

`tests/LanzouRegression` 使用可控 HTTP 响应测试文件、密码、分页、子目录、任务重建、独立分享刷新、异常及请求边界。UI 回归覆盖平台能力、粘贴文案、账号入口和续传记录。

真实链接的验证结果保存在本次发行包的「功能验证.json」及本地 `artifacts/lanzou-references/live-result.log`。真实下载验证只读取文件分片，不安装或运行分享中的 APK。模拟测试通过不代表所有蓝奏页面版本都已实际验证。
