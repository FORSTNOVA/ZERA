# UI 重构与 Android 预览验收

日期：2026-11-09。Android 版本：3.0.0-preview.1。Windows 沿用 2.13.0 的业务版本。

## 已通过

- Windows Release 构建、现有 WPF UI 回归：深浅主题、四页导航、最小窗口、七种抽屉、键盘与焦点、登录控件及设置。
- .NET 10 共享核心七组回归：下载、WebDAV、蓝奏云、原生云盘、原生登录、会员查询、Tracker。
- Android x86_64 模拟器：HTTP 多 Range、WebDAV 认证与目录、切换平台后任务仍绑定原账号、分片下载在进程重启后恢复、加密状态落盘与恢复。
- Android 原生 BT：普通下载、2/4/8 独立会话拆分与合并，私有种子保留内嵌 Tracker 并排除额外公共 Tracker。
- 合成下载文件均校验 SHA-256：`047eb196e8f681dc3967913345ff4af3371dce9d8bdd357515c12c5f110c8205`。
- Android 界面：十个平台入口与能力区分、轮询保留未保存设置、保存设置、深色/浅色/跟随系统、页面无横向溢出、BT 完成文件通过 ContentProvider 读取且字节一致。
- 最终交付 APK 已在测试模拟器安装并启动，无启动崩溃；检查 ARM64/x86_64 原生库、五份许可证资源、非调试清单与签名。测试专用桥接入口及 WebView 远程调试调用均已从交付程序集排除。

自动验收原始结果随交付提供在 `validation/` 中；复现入口见 `tests/AndroidSmoke/README.md`。

## 交付边界

Android 是可安装预览版，并非 Windows 全部功能已完全对齐。尚缺的桌面特定操作及移动端差异见 `docs/ANDROID.md`。
未使用真实网盘账号进行各平台完整下载联调；ARM64 库与应用已编译打包，尚未在 ARM64 真机运行。
应用使用本机构建环境的调试证书签名，适合预览测试；正式发布应使用独立的长期发布密钥。
下载默认保存在应用专属目录，卸载会删除，请导出重要文件。
