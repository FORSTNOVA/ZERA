# Android preview.2 功能补齐与验收

日期：2026-11-09（Asia/Shanghai）。包名 `com.zera.downloader`，版本 `3.0.0-preview.2`，版本号 2。沿用 preview.1 的本机构建签名，可覆盖安装并保留应用资料。

## 本次补齐

| Windows 功能 | Android 实现 |
| --- | --- |
| 图片二维码识别 | 系统图片选择器、本地 ZXing 解码，支持旋转和反色；接收图片分享 |
| 网盘文件操作 | 夸克新建目录、分享转存、转存后下载、移入回收站及所选文件永久删除 |
| 账号信息与导出 | 容量查询；纯链接、带文件名、curl、aria2、Motrix 导出 |
| BT 子任务控制 | 2/4/8 会话子任务进度、速度、节点数、独立暂停/继续与整组控制 |
| 本地文件管理 | 选择公共目录、手动/自动复制完成结果、单文件另存为、删除本地文件 |
| 托盘与小窗 | 带进度和暂停/继续的系统通知；用户授权后显示可拖动悬浮窗 |
| Tracker 管理 | 订阅名称与地址编辑，保留启用状态与缓存 |

同时修复了小屏设置项、夸克批量操作栏挤压，任务轮询丢失按钮焦点，以及相同分享内容重复导入的处理。

## 验收范围

- .NET Android Release 测试构建通过，无新增编译警告或错误。
- 新增核心回归：原生图片解码、旋转/反色、坏图片；模拟夸克转存、转存后按新文件 ID 下载并校验内容、目录创建、容量、删除确认、过期目录令牌和回收站精确清理；BT 子会话独立暂停/继续、进程重启保持暂停。
- 公共目录回归：通过真实 Android 系统目录选择器获得授权；授权跨进程重启保留；手动、重复与自动导出均校验字节；真实通知栏暂停/继续；删除本地文件后公共副本仍在；清除目录后要求重新选择。
- 界面回归：实际点击转存、删除、新建目录、容量和 Tracker 编辑入口；确认默认可恢复删除；保留子任务展开与操作焦点；取消图片选择后桥接继续工作；360px 宽度设置项可读且页面无横向溢出。
- 原生悬浮窗回归：未授权不能开启，授权后显示进度，实际按钮控制暂停/继续，关闭后服务轮询不重开。
- 原有 Android 下载回归重新通过：HTTP/WebDAV、多账号绑定、进程重启恢复、加密状态、普通 BT、2/4/8 拆分与私有 Tracker。下载结果 SHA-256 与合成源一致。

合成源文件 SHA-256：`047eb196e8f681dc3967913345ff4af3371dce9d8bdd357515c12c5f110c8205`。
交付目录 `validation/android-preview.2/` 提供各组 JSON 结果；复现脚本位于 `tests/AndroidSmoke/`。

本轮新增验收共 55 项：核心 24、公共目录/通知 11、界面 15、悬浮窗 5；另保留重新通过的原有下载/BT 29 项结果。
交付 APK 经签名检查和模拟器覆盖安装启动检查，包含 ARM64/x86_64 原生库与六份许可证资源。

## 尚未验证或未对齐

验收设备为 Android x86_64 模拟器；ARM64 已构建，但尚未做 ARM64 真机验收。
网盘远端变更使用内存模拟传输验证，未操作真实网盘文件，也未完成十个平台真实账号下载联调。
夸克下载后自动清理中转文件、Windows 自定义播放器/预缓冲配置、任意分片根目录以及 Windows DPAPI 资料直接迁移仍未对齐。
公共目录使用完成后复制，下载分片仍先写入应用专属目录；应用专属数据在卸载后会删除。

签名为本机构建环境的预览签名，正式发布需维护者使用长期发布密钥。交付包不包含测试专用入口、WebView 远程调试或任何测试账号资料。
