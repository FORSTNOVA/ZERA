# ZERA Android 3.0.0-preview.2

Android 9 / API 28 起，支持 ARM64 真机和 x86_64 模拟器。界面为离线随包资源，
下载、平台 API、凭据存储及后台服务在应用内运行，不要求连接 Windows 电脑。

## 构建与代码结构

安装 .NET 10 SDK、Android 工作负载、Android SDK 36、JDK 21 后，在项目根目录执行：

```powershell
./scripts/build-android.ps1
```

生成 `dist/ZERA-Android-3.0.0-preview.2.apk`。这是使用本机开发签名的预览包；
正式发布需使用维护者自己的签名，并妥善保留密钥。构建脚本不导出或打包签名私钥。
Windows 仍使用 `dotnet build ZERA.slnx -c Release`，不需要 Android SDK。

- `src/ZERA.Portable`：直接编译原 `ZERA.Core` 的平台协议与下载源码，适配原有 JSON 对象模型。
- `src/ZERA.Android`：Android Activity、前台下载服务、Keystore 加密存储、文件分享及原生 BT 桥接。
- `src/ZERA.Android/Assets`：下载、任务、账号、设置四个页面，支持深浅主题与手机/平板布局。
- `tests/PortableRegression`：将已有核心回归用例运行于 .NET 10，避免重新实现一套不同的平台行为。

Windows 的 WPF、DPAPI、GDI+ 和 Windows Python 运行时不会打入 APK。二维码图片使用同版本 ZXing 的跨平台程序集与 Android Bitmap 在本地识别。
夸克账户信息/扫码换取 Cookie 在移动端使用平台 TLS；接口仍可能受服务端风控影响。

## 功能与平台差异

共享核心包含夸克、百度、WebDAV、阿里、123、115、天翼、移动、迅雷及蓝奏云。
平台入口根据能力显示；新增六家的真实账号验证边界沿用 [原生接入说明](NATIVE-CLOUDS.md)。
代码接入和模拟回归不等于全部真实账号均可授权下载。

- 分享解析、网盘目录、选择文件/目录递归下载、HTTP(S) 直链下载。
- 多线程 Range 下载、暂停/继续、直链刷新、取消、历史任务与重启后手动恢复。
- 多账号按原账号绑定下载；扫码、密码及验证流程复用原协议。阿里/115 仍需要自己的开放平台应用参数。
- Android Keystore AES-GCM 加密整个账号与任务状态；原始登录密码不持久化，不兼容直接复制 Windows DPAPI 密文。
- 前台下载通知与有时限的唤醒锁。Android 限制或系统终止后保留断点；不会承诺永久驻留。
- 通过系统选择应用打开本地文件；完整文件可使用系统分享面板保存到用户目录。
- 从系统选择图片识别二维码，也可接收其他应用分享的图片、文字与种子；图片不上传。
- 夸克新建目录、分享转存（可转存后下载）、网盘文件删除。默认放入回收站；永久删除需额外勾选并确认，只清理所选文件对应记录。
- 网盘容量查询、带文件名/纯链接/curl/aria2/Motrix 五种直链导出，以及 Tracker 订阅名称和地址编辑。
- 普通 BT v1 种子/磁力，以及本地 BT v1 种子的 2/4/8 会话拆分下载；Tracker 手动列表和订阅。
- BT 整组与独立子会话暂停/继续，展示子会话进度、速度和连接数；重启后保持暂停，继续时重新校验。
- 拆分会话只请求自己的块范围，完成后重验原种子的 SHA-1，发布到独立 `result` 目录。
  工作文件使用原生文件存储，需要按（子任务数 + 2）倍内容大小预留空间。

后台下载通知显示进度，并提供全部暂停/继续操作。下载悬浮窗需用户主动开启系统“显示在其他应用上层”权限；
仅在下载服务运行时显示，支持拖动、暂停/继续、打开主界面和关闭。全部任务暂停或结束后随前台下载服务关闭，可从通知继续。

尚未完全对齐的部分：夸克中转文件的下载后自动清理、Windows 自定义播放器路径/预缓冲策略、
任意分片根目录、Windows 配置/DPAPI 账号资料直接迁移，以及 Windows 托盘菜单的所有附属操作。
移动端使用通知与授权悬浮窗替代托盘，网盘下载可使用两种写入模式。
边下边播通过外部播放器打开已写入文件，实际可播性由媒体格式和播放器决定。

下载默认位于应用专属外部目录，**卸载应用会删除此目录中的文件**。
重要文件请在任务完成后使用“保存或分享文件”导出。

## 公共目录与另存为

设置中的“选择目录”调用 Android 系统目录选择器，应用只获得用户选中目录的持久写入授权。
下载引擎先在应用目录中完成可随机写入的暂存，再通过系统文档 API 顺序复制完整结果；不会把 URI 伪装为普通路径写入。
可手动导出已完成任务/BT 整组、单个文件另存为，或开启“完成后自动导出”。
每次目录导出创建新的 `ZERA-任务ID-随机后缀` 子目录，不覆盖已有副本。更换或清除目录会释放旧授权。
公共副本卸载后仍保留；应用专属暂存和断点仍会随卸载删除。导出需要额外空间，空间不足或授权撤销时保留部分副本并提示手动重试，不无限自动重试。

“仅移除记录”保留本地文件；“删除本地文件”需确认，删除该任务文件和续传元数据，不删除已经导出的公共副本。

## 本地状态与安全边界

账号和网盘任务保存在应用私有目录的 `state.enc`；Android 自动备份关闭。
BT 索引和断点保存在应用下载目录的 `BT/` 下，重新启动保持暂停，继续时由引擎重新校验。
移除 BT 任务保留文件。不要手动删除断点或工作目录后期待自动恢复。

特权 WebView 只加载固定离线资源，不打开远端网页、不执行服务端页面脚本，
外部验证链接交由系统浏览器处理。桥接消息采用有界异步队列，文件名等动态内容使用安全 DOM 文本节点。
WebDAV 的认证范围与禁止重定向规则复用现有实现；HTTP 连接需要用户在配置时明确选择允许。

BT 原生库来源、许可证和哈希见 [依赖来源](../src/ZERA.Android/Libraries/PROVENANCE.md)。

## 验证

Windows 重构版通过项目已有的 WPF UI 回归，覆盖深浅主题、四页导航、最小窗口、七种抽屉与登录控件。
共享核心在 .NET 10 下通过下载、WebDAV、蓝奏云、六家原生网盘、原生登录、会员查询及 Tracker 回归。
Android x86_64 模拟器已通过本地 HTTP/WebDAV 下载、暂停和重启恢复、账号绑定、加密状态、
普通 BT、2/4/8 会话拆分、私有种子 Tracker 保留、结果文件导出读取及深浅主题验收。
新增 QR 图片（含旋转/反色）、模拟夸克转存与删除保护、子会话独立控制和重启恢复、真实 SAF 目录授权/导出、自动导出与通知按钮也有独立回归。
下载结果使用 SHA-256 与合成源文件逐字节校验。详细结果见随交付包提供的验证记录。
ARM64 已编译打包，尚未在 ARM64 真机运行；尚未使用真实网盘账号做完整平台下载联调。

Android 前台服务限制依据：
https://developer.android.com/develop/background-work/services/fgs/timeout
；Keystore 依据：https://developer.android.com/privacy-and-security/keystore 。
